SOFTBALL READY — FUNCTIONALITY BUILD 1

This package contains four files:
1. players.html
2. login.html
3. supabase-app.js
4. supabase-config.js

WHAT THIS BUILD DOES
- Creates real account signup and login.
- Requires login before saving a player profile.
- Saves the Player Profile form into the Supabase players table.
- Keeps membership/searchability off until payment is added later.

UPLOAD STEPS
1. Save this ZIP to Google Drive.
2. On your Mac, download and unzip it.
3. Upload all four files to the main level of the softball-ready-preview GitHub repository.
4. Replace players.html and login.html when GitHub asks.
5. Commit the upload.

ONE REQUIRED EDIT
Open supabase-config.js in GitHub and replace:
PASTE_YOUR_PUBLISHABLE_KEY_HERE

with the Publishable key copied from Supabase > Settings > API Keys.
Do not use a Secret key.

After Vercel deploys, we will configure the approved login redirect URL in Supabase and test a real account and player profile.
